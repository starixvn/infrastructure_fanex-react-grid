You have reports within large data rows. You want to render the data grid faster than normal way. Fanex.React.Grid Component is a solution.

In this tutorial I'm going to show you how to use Fanex.React.Grid component implemented with Facebook's React library. I use the JSX syntax to write the react grid component. So let's get started.

Fanex.React.Grid's layout

Parameters:

  • ShowTitle: Boolean value. If true, the data grid title will show. Default is false.
  • TitleText: String value. The text you want to show at grid title. Default is empty.
  • NoDataText: String value. The text you want to show in gird when it doesn't have any records. Default is "No data.".
  • ShowFooter: Boolean value. If true, the grid footer will show. Default is false.
  • OddEvenRow: Boolean value. If true, the data grid odd and even row will show with different background color. Default is false.
  • IsHighlightHover: Boolean value. If true, the content row will have high light background when hovered. Default is false.
  • IsPaging: Boolean value. If true, the paging control will show. Default is false.
  • IsServerPaging: Boolean value. It works when IsPaging = true. If true, your grid data will paging in the Server. Default is false.
  • PagingOptions: Object value. It works when IsPaging = true. Contain all paging properties.
    • PageIndex: Integer value. Value of page index. Default is 0.
    • PageSize: Integer value. Value of page size (number of rows in 1 page). Default is 100.
    • PageSizeList: Array value. Array of PageSize. Default is [50, 100, 200, 500].
    • PagingCallBack: Function type. If IsServerPaging is true, you must define this function to call back data after paging. Default is undefined.
    • NumberOfPage: Integer value. Value of number of pages. Default is 0.
    • TotalItems: Integer value. Value of total rows in grid (all pages). Default is 0.
  • MaxContentHeight: Integer value. Max height of the grid, when the grid's height is larger, the scroll bar will show. Default is 500.
  • MaxContentWidth: Integer value. Max width of the grid, when the grid's width is larger, the scroll bar will show. Default is 1000.
  • IsRenderLargeData: Boolean value. If true, data will be rendered a part, and after scroll to bottom of grid data (***) will be rendered more. Default is false.
  • RenderLargeDataCallBack: Function type. The function at client which call data (***) if you want to get it from server. Make sure it return the continuous data of the grid. Default is undefined.
  • GridWidth: Integer value. Width of the grid. It's calculated by total of all column's width. Default is 0.
  • ColumnWidthList: List integer. List of column's width. The base width that all column in header, body and footer must follow. This is the most important property of ReactGrid so that it must be not null. Default is [].
  • HeaderStyle: Integer value. Number of header line. Default is 1.
  • GroupHeaders: Object array. Array of group header column cell. Each object contain a column. Default is [].
    • Index: Integer value. Index of group header cell. This property must be set exactly.
    • Name: String value. Name of group header cell.
    • Width:
    • MergeColumnNumber: Integer value. Number of merge columns. Default is 1.
    • MergeRowNumber: Integer value. Number of merge rows. Default is 1.
    • Text: String value. Group header text. Default is empty.
    • TDClass: String value. Custom css of header cell. Default is empty.
  • HeaderColumns: Object array. Array of header column cell. Default is [].
    • Index: Integer value. Index of group header cell. This property must be set exactly.
    • Name: String value. Name of group header cell.
    • Width:
    • MergeColumnNumber: Integer value. Number of merge columns. Default is 1.
    • MergeRowNumber: Integer value. Number of merge rows. Default is 1.
    • Text: String value. Group header text. Default is empty.
    • TDClass: String value. Custom css of header cell. Default is empty.
  • BodyRows: Object array. Array of body column cells. Default is [].
    • RowIndex: Integer number. Row index value.
    • RowClass: String value. Custom css of body cell. Default is empty.
    • Columns: Object array. Array of body cells. Default is [].
      • Index: Integer value. Index of group header cell. This property must be set exactly.
      • Name: String value. Name of body cell.
      • TDClass: String value. Custom css of body cell. Default is empty.
      • CellDataType: Object value. The type of displaying value of the cell. Default is CellDataType.Text. Options:
        • Text: Example: The text
        • Integer: Example: 1,234
        • IntegerRedPositive: Example: 1,234
        • IntegerRedNegative: Example: -1,234
        • Decimal: Example: 1,234.56
        • DecimalRedPositive: Example: 1,234.56
        • DecimalRedNegative: Example: -1,234.56
        • DecimalRedAbsNegative: Example: Value is -1,234.56, Display Text is 1,234.56
        • DecimalRedParenthesesNegative: Example: Value is -1,234.56, Display Text is (1,234.56)
        • Percentage: Example: Value is 0.12, Display Text is 12%
        • PercentageRedPositive: Example: Value is 0.12, Display Text is 12%
        • PercentageRedNegative: Example: Value is -0.12, Display Text is -12%
        • PercentageRedAbsNegative: Example: Value is -0.12, Display Text is 12%
        • PercentageRedParenthesesNegative: Example: Value is -0.12, Display Text is (12%)
        • DateTime: Example: 1/31/2015
        • DateTimeMMddyyyy: Example: 01/01/2015
        • DateTimeMMMdyyyy: Example: Jan 1, 2015
        • DateTimedMyyyy: Example: 31/12/2015
        • DateTimeMmmmddyyyy: Example: January 01, 2015
      • Value: Object value. Value of the cell. Default is null.
      • MergeColumnNumber: Integer value. Number of merge columns. Default is 1.
      • MergeRowNumber: Integer value. Number of merge rows. Default is 1.
      • IsHightLight: Boolean value. If true, the row will be show in high light background. Default is false.
      • CellClass: String value. Custom css of the cell. Default is empty.
      • TextAlignment: String value. Alignment of cell text. Value: "left", "right" and "center". Default is "right".
      • DisplayText: String value. If it's set, the grid will show this instead of calculate the Value. Default is empty.
  • FooterRows: Object array. Array of footer column cell. The properties are the same with BodyRows. Default is [].
